# メモリレビューの表示

[English](2026-09-14-memory-review-layout.md) | 中文

メモリレビューダイアログは、クリップされた子要素だけでなく外側の Modal カードをサイズ指定する。候補テキストのない提案は recall/search テレメトリとレコードをデフォルトで非表示にする。明示的な technical-record トグルで保持レコードを表示できるが、レビュー呼び出しやデータ削除は行わない。Host 側の受理ポリシーは変更しない。3 つのメモリスコープは引き続き分離される。

検証: メモリコンポーネントのフォーカスしたテスト。ブラウザレイアウトは client バンドル更新後にライブ検証が必要。
