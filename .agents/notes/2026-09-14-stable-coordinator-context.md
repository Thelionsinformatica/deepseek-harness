# Stable coordinator and bounded compaction

English | [中文](2026-09-14-stable-coordinator-context.zh.md)

The Web profile opts into adaptiveRouting.coordinatorMode. Automatic admission uses the saved principal route and preserves manual mode. Historical images no longer select the auxiliary vision route as coordinator in this mode. Image capability remains enforced by the normal admission and adapter paths.

The summarizer checks heuristic input plus output reserve against declared capacity before inference. An oversized compaction fails explicitly and preserves history instead of submitting an impossible request and continuing the normal step. Exact tokenization and hierarchical summarization are not implemented by this guard.

Focused tests: 22 model-selection tests and 82 compaction tests passed. No paid model inference was performed for validation. Full browser/model execution and a keyless assembled snapshot of the new option are pending. Vision delegation is not added by this change; only the unwanted replacement of the coordinator is addressed.
