# 安定コーディネータと有界コンパクション

[English](2026-09-14-stable-coordinator-context.md) | 中文

Web profile は adaptiveRouting.coordinatorMode にオプトインする。自動 admission は保存された主ルートを使い、手動モードを保持する。このモードでは、履歴画像が補助ビジョンルートをコーディネータとして選択しなくなる。画像能力は通常の admission とアダプタ経路で引き続き強制される。

要約器は推論前に、ヒューリスティックな入力量と出力予約を宣言容量と照合する。過大な compaction は不可能なリクエストを送信して通常ステップを継続するのではなく、明示的に失敗して履歴を保持する。正確なトークン化と階層的要約はこのガードでは実装しない。

フォーカスしたテスト: model-selection 22 件、compaction 82 件が通過。検証に有料モデルの推論は使用していない。ブラウザ/モデル全体の実行と新オプションの keyless 組み立てスナップショットは未了。ビジョン委譲はこの変更では追加しない。コーディネータの意図しない置き換えのみを解消する。
