# Agent Note: Leon 的受控自动回忆

Status: implemented

[English](2026-08-22-controlled-automatic-memory-recall.md) | 中文

## 问题

显式 `memory_search` 很安全，但依赖模型记得调用它。Leon 需要有用的连续性，同时不能把完整对话复制到持久存储、跨 workspace 泄漏事实、把已存凭据暴露给远程模型，或让保留文本变成隐藏指令。

## 决策

- **回忆是现有 Consumer 上的选择加入配置。**`automaticRecall` 不改变提供方约定和 4 个工具名称。Leon preset 使用 4 条记录和 4,000 字符的边界启用它；其他 preset 保持仅显式行为。
- **每轮只有第一个被接受的步骤执行回忆。**该步骤中由人类编写的文本会成为有界提供方查询。工具结果、插件上下文和模型文本绝不会成为查询。后续工具循环步骤不会重复快照。
- **Workspace 解析仍具有权威性。**agent 会话 cwd 通过 `ctx.workspaceRegistry` 解析；workspace 缺失或未注册时不产生回忆。模型仍不能选择作用域，也看不到 workspace id 或原始路径。
- **回忆内容持久、有界且不可信。**安全命中会编码为带引号的 JSON，以具有来源信息的插件快照放在当前人类消息之前。静态策略和快照都声明记录值是数据而不是指令。会越过字符边界的记录将被跳过，绝不会被截断为含义不清的片段。
- **自动回忆只读并采用开放失败。**它不会执行创建、更新、遗忘、提取、摘要或对话捕获。取消会抑制快照。提供方失败会被记录，而模型轮次会在没有可选记忆的情况下继续。
- **凭据过滤在面向模型的边界强制执行。**常见 private key、API key、token、JWT、密码标签和凭据模式会使 `memory_remember` 与 `memory_update` 被拒绝。显式搜索和自动回忆都会省略匹配的已存记录。这是保守的纵深防御，并不承诺识别每一种 secret 格式。
- **候选遥测绝不保留查询内容。**运行时事件和持久影子记录会记录查询长度、候选数量、分数和策略结果，但绝不记录临时查询文本。由于检测无法保证识别每一种 secret 格式，被阻止和需要确认的决策也遵循同一规则。

## 验证

真实 agent loop 集成会预置安全记录、类似凭据的记录和另一 workspace 的记录。测试证明第一次请求只包含一个安全且不可信的快照，排除 secret、workspace id、路径和另一 workspace，并且工具循环中不会再次注入。显式搜索结果报告一个被隐藏的敏感命中。原始存储保持不变，证明回忆没有写入。第二项集成证明类似凭据的 `memory_remember` 会在提供方持久化之前失败。候选遥测覆盖证明运行时事件和持久记录都不含原始查询，包括被策略阻止的类似凭据查询。

## 考虑过的替代方案

- **始终要求显式 `memory_search`**：拒绝，因为只要模型没有选择该工具，安全记录就会保持不可见，削弱普通后续问题的连续性。
- **自动提取并保留每个对话轮次**：拒绝，因为回忆并不授予创建持久事实的权限。自动写入会产生独立的同意、纠正、删除和隐私问题。
- **把回忆记录直接放进 system prompt**：拒绝，因为保留的用户数据不得获得指令优先级。带来源信息的不可信快照会在持久日志中清楚分离策略与数据。

## 后果

Leon 现在可以在无需每轮都调用工具的情况下回忆相关项目事实，同时保留显式写入和精确 revision 纠正。动态回忆会消耗有界后缀 token，而词法检索可能漏掉改写表达；更丰富的检索仍是提供方职责。已存文本不会获得指令权限。自动持久写入、全局记忆、跨 workspace 回忆和无人监督学习仍不在范围内；独立的[影子提取器](../feature/2026-08-22-shadow-memory-candidate-extraction.zh.md)会创建审查候选项，但不会更改记忆。
