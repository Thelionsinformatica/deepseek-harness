# Agent Note: Leon 本地化工作状态

Status: implemented

[English](2026-08-23-leon-localized-work-status.md) | 中文

## Problem

聊天活动标签使用了以“Deep”开头的英文短语，但它描述的是通用工作状态，并不表示模型提供方。在 Leon 产品中，这看起来像 DeepSeek 路由披露；巴西葡萄牙语界面的重试行还会回退成英文。本地模型失败时，用户因此既难以辨认是谁在工作，也难以判断页面是否仍然活跃。

## Decision

实时轮次状态通过 conversation locale 条目标识 Leon。英文显示 `Leon is working…`，巴西葡萄牙语显示 `Leon está trabalhando…`，每种受支持语言都拥有对应条目，不依赖组件中的固定字面量。

重试展示使用持久重试节点记录的提供方。Ollama 尝试使用本地模型标签；其他提供方保留中性的模型请求标签。活动中的重试在现有变化倒计时之前显示省略号，已完成与已取消的行则保留静态标签。巴西葡萄牙语回退包会翻译所有重试状态、重试延迟和失败原因。

## Alternatives considered

**只替换实时活动短语。** 拒绝，因为本地 Ollama 失败后，已修正的葡萄牙语状态下方仍会立即出现英文重试文案。

**把每次重试都称为本地模型重试。** 拒绝，因为 Gemini 和手动配置的远程提供方共用同一重试投影；持久 provider 字段可提供准确的本地措辞，且不会错误标记云端工作。

**移除倒计时以完全匹配更短的句子。** 拒绝，因为变化中的数值是退避期间页面仍然活跃的直接证据。句子与尝试次数保持完整，其后继续显示倒计时。

## Testing

Conversation 组件测试固定本地化实时轮次条目、耗时呈现、提供方感知的 Ollama 标签、中性提供方标签、重试状态和倒计时更新。locale 测试固定巴西葡萄牙语工作与重试文案。组装后的 Web 快照固定运行中会话状态的活动标签。

## Consequences

Leon 会标识自身工作，不会让人误以为已选择 DeepSeek；本地重试行用巴西葡萄牙语说明当前动作，同时继续展示实时进度。重试措辞依赖准确记录 provider id；未知或远程提供方会刻意收到中性文案，而不是猜测的品牌名称。
