# Agent Note: 仪表板历史就绪状态与部分费用

Status: implemented

[English](2026-09-06-dashboard-history-readiness.md) | 中文

## Problem

历史无法读取的对话仍可能显示就绪状态。过窄的指标卡片可能隐藏 API 估算不包含未定价调用的警告。

## Decision

活动投影将 `openError` 视为会话错误。仪表板文案明确 API 金额是估算而非账单；标签和说明在响应式卡片内换行。持久化事件及其验证保持不变。

## Alternatives considered

**忽略未知事件**可能丢失模型可见历史，不能作为恢复机制。服务器和客户端产物必须一起部署。

**仅在提示框中显示费用警告**会使普通浏览和触摸用户无法直接获知关键不确定性。

## Consequences

卡片可能占用更多垂直空间。定向组件回归覆盖错误状态和部分费用文案；构建后的浏览器检查验证换行。这些变更既不会为未知调用定价，也不证明代理任务质量。
