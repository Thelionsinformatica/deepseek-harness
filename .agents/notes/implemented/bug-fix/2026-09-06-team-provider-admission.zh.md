# Agent Note: 团队提供方准入

Status: implemented

[English](2026-09-06-team-provider-admission.md) | 中文

## Problem

不可用的提供方会占用不可复用的队友名称和名额。公布不可用的创建模式会引发重复失败。

## Decision

成员表在写入创建记录之前检查持续会话能力。工具模式在提供方注册变化时刷新，只公开可用的创建模式。直接服务调用仍执行准入检查。

## Alternatives considered

**删除失败成员**会丢失真实创建证据，并削弱不可变身份约束。准入后的失败仍保留记录。

**仅靠提示词限制**无法阻止直接调用者占用名额。

## Consequences

准入后移除提供方仍可能产生持久化失败。单元回归覆盖提供方缺失、拒绝准入后成功复用名称、提供方移除以及准入后失败记录的保留。模型质量比较和最终审查预算仍需单独验证。
