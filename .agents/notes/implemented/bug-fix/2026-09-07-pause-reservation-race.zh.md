# Agent Note: 并发预订后重试宿主暂停

Status: implemented

[English](2026-09-07-pause-reservation-race.md) | 中文

## 问题

标准输入暂停可能恰好在工作者预订调用之前读取任务修订。陈旧变更被拒绝且仅记录错误，使任务继续运行。

## 决策

实验 CLI 仅在任务仍运行时重试陈旧暂停修订。次数上限为剩余调用额度加一。它仅确认已提交的变更。任务服务保留修订检查；STOP 和恢复不采用新的重试策略。

## 考虑过的替代方案

**移除修订检查：** 会削弱依赖陈旧控制被拒绝的调用方。

**重试所有错误：** 可能隐藏终态或授权失败。

## 后果

受控双工作者测试在第六次调用时暂停，并在新进程中恢复，于第 31 次调用完成，保留截止时间和任务。这证明一次受控恢复，不证明断电恢复或任意并发宿主。普通配置保持不变。
