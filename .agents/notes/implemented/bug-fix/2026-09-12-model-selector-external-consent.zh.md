# Agent Note: 模型选择器的外部授权

Status: implemented

[English](2026-09-12-model-selector-external-consent.md) | 中文

## Problem

只要存在自适应路由，自动模型面板就会提供外部 API 授权，即使部署策略没有声明外部备用路由。该控件暗示运行配置能够使用一条实际不存在的数据传输路线。

## Decision

`session.models` 报告自动策略是否声明外部备用路由。模型选择器只在该事实为真时显示授权控件。旧宿主省略此字段，客户端将省略解释为 false。目录行仍是配置元数据，不是实时健康声明。

## Alternatives considered

**始终显示禁用控件。** 未采用，因为这仍会让人误以为部署具有外部路线。

**从目录中的云提供方推断可用性。** 未采用，因为可手动选择的提供方不能证明自动策略可以路由到它。

## Consequences

仅本地部署获得更简洁的自动面板，也不会收集没有意义的授权。具有外部备用路由的部署保留原有警告和默认拒绝选择。选择器若要把已配置模型标记为可运行，仍需独立的运行时健康报告。
