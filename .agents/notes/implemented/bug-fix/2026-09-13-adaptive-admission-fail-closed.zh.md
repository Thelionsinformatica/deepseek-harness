# Agent Note: 自适应接收错误时阻止执行

Status: implemented

[English](2026-09-13-adaptive-admission-fail-closed.md) | 中文

## Problem

自动路由解析失败可能保留已保存的外部模型。未定价的仪表板调用也可能显示零美元标题。

## Decision

提示接收在输入入队前拒绝分类器和解析错误。恢复升级传播失败，而不是调度此前的路由。存在未定价调用且没有已定价调用时，仪表板总额显示未知值。手动模型选择保持不变。

## Verification

针对性 API 测试在不调用 followup 的情况下拒绝分类器和不可用适配器错误。仪表板测试断言未知标题且不存在零美元声明。这些测试不证明提供方驻留位置或账单对账；任意配置的外部主路由仍需单独审查策略。

## Alternatives considered

**保留此前路由：** 这会隐藏选择失败，并可能越过预期执行边界。

**编造费率：** 这会掩盖计费不完整，而非解决问题。

## Consequences

自动请求可能被拒绝，而手动选择的路由仍可用。缺失价格保持可见，并需要经过验证的费率配置；此更改不添加价格，也不改变存储的用量。
