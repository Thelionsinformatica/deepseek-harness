# Agent Note: 修订确认与含图压缩准入

Status: implemented

[English](2026-09-15-memory-confirmation-and-compaction-admission.md) | 中文

## 问题

纠正后的记忆继承了属于不同文本的确认与置信度。仅支持文本的辅助摘要模型可能收到含图历史；自动压力处理可能吞掉其 LLM 错误，在未成功建立检查点的情况下继续执行。

## 决定

两种本地历史模式下，正文变更都会清除当前置信度与验证字段。时间历史保留原始修订。原摘要路由不能读取图片时，含图压缩仅选择兼容且已分配的视觉路由。范围预算考虑两条路由的容量，pre-step 准入传播 LLM 错误。不增加提供方或授权。

## 验证

记忆与压缩专项测试通过 178 项。真实 Loader 个人记忆提供方与 MCP 桥接测试另通过 67 项，包括修订失效和实际重复分页游标的 stdio 服务器。宿主构建与 lint 成功完成。这些是不使用密钥的测试，不证明模型质量或用户实时会话恢复成功。

## 考虑过的替代方案

保留旧确认会误表述新正文。丢弃图片或静默更换协调者会丢失证据或改变用户意图。增加上下文与重试预算只会掩盖不兼容路由，而不是修复它。

## 后果

不重写或追溯核验既有记忆。普通聊天视觉委派、新建记忆的事实来源强制校验以及实时重启验收仍是独立工作。保留全部既有工作区修改；不变更生产凭据或模型分配。
