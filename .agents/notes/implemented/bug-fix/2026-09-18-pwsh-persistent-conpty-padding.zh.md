# Agent Note: 持久化 pwsh 输出夹带 ConPTY 填充行

Status: implemented

[English](2026-09-18-pwsh-persistent-conpty-padding.md) | 中文

## 问题

在负载下，持久化 pwsh 工具返回的命令输出可能带有一个仅含空白的前缀行——ConPTY 在回滚缓冲中留下的视觉填充，落在真实 START 标记与命令首行输出之间。提取逻辑原本已修剪完成状态数字之后的水平填充，但未处理输出之前的填充行，因此严格消费者会看到多余的 `   \n` 前缀。

## 决定

`commandOutput` 仅在前置的纯空白行之后存在真实输出时才将其剥除。整条输出皆为空白的命令保持原样，与既有状态行填充先例一致。

## 验证

`loader-composition.spec.ts` 在产生该伪影的同一并行聚合负载下通过（7 个文件，129 项测试），单独运行亦通过。功能契约——重生 shell 从工作区起步——本就成立；本次修复清除的是提取噪声。

## 考虑过的替代方案

无条件修剪全部前导空白会吞掉真实的纯空白首行。将其归为测试抖动则会把真实的保真度泄漏留在模型可见输出中。

## 后果

提取对终端渲染伪影略微更宽容。标记锚定、wrapper 剥离以及纯空白输出的边界用例均不变。
