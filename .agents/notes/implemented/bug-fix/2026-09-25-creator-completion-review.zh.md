# Agent Note: 创造模式完成审核与明确的新会话默认值

Status: implemented

[English](2026-09-25-creator-completion-review.md) | 中文

## 问题

创造模式会话可以在没有 Leon 要求的任务证据和独立审核时完成目标。preset 名单的「当前使用」徽记也混淆了新会话默认值与既有对话的 preset。

## 决策

随附的 `cordis` 组装启用 Leon 的已完成任务与独立 `spawn` 审核配置，并采用相同的审核限制。现有宿主辅助审核路由仍具有决定权。审核者 driver 添加私有作用域中的证据和结构化输出工具；这些名称不能加入全局 `completionAuditorTools` 限制。宿主 guard 拒绝审核者使用协调者的能力。

创造模式还采用 Leon 的 Windows 进程终止与受管理服务检查，同时保留普通创作工具和持久化的 sandbox 覆盖值。preset 名单徽记以英语、葡萄牙语和中文明确表达其含义：新会话默认预设。当前会话标题仍是实际 preset 的信息来源。

这项组装决策补充了[目标工具权限决策](../feature/2026-07-19-model-facing-goal-tools.zh.md)，不替代该机制或[创造模式入口引导](../feature/2026-08-10-creator-guidance-introduce-cue.zh.md)。

## 考虑过的替代方案

仅依赖 prompt 的审核无法阻止完成状态变更。替换持久化的完全访问选择会暗中更改用户策略。新建审核 provider 或硬编码模型会重复现有宿主路由并产生偏离风险。因此拒绝这三种方案。

## 后果

证据缺失、审核拒绝、没有结构化结论或审核无法运行时，目标保持活动状态。现有模型、凭据、限制和保存的权限选择保持不变。创造模式保留相当于 shell 的组装权限；新增检查不能隔离任意创作的代码。已挂载的 agent 需要重新挂载才能采用组装编辑。

## 测试

无需密钥的 Web 组装测试加载随附的创造模式 preset，并通过脚本化适配器运行真正隔离的 `spawn` 审核者。测试固定缺失和未完成任务的拒绝、有效结构化批准、拒绝、非结构化输出的拒绝、审核工具隔离、进程策略拒绝、完全访问状态保留以及编程工具保留。组件测试固定葡萄牙语徽记和无障碍名称，不改变选择行为。这些测试不涵盖外部推理或实际部署重启。
