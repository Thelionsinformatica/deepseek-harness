# Agent Note: 可操作的完成反馈与已分配的证据页面

Status: implemented

[English](2026-09-25-goal-review-feedback.md) | 中文

## 问题

一次真实完成流程在 PASS 后重复同一个被拒绝的调用，因为审查待办仍未完成。审查员也在完整记录已经内联提供时请求了未分配的证据页面。正确拒绝保护了安全性，但展示的能力和反馈引导了可避免的调用。

## 决策

[goal 工具](../../../../packages/goal/tool-goal/README.zh.md)在明确审查通过后返回宿主编写的 `review.nextAction`，并在策略和未完成列表错误中指明 `todo_write`。反馈保留完整规范列表，要求执行器仅记录真正完成的工作。不会推断或自动改变任何状态。

审查提示词明确标识内联或分页交付。仅分页审查会展示并允许 `completion_evidence_read`，即使部署验证工具名称包含该工具也一样。执行守卫、指定 agent（智能体）访问、页面完整性、产物新鲜度和同轮复用检查仍然强制执行。

此决策补充[待办顺序与证据交付](2026-09-20-completion-incomplete-evidence-gate.zh.md)以及[审查员能力限制](2026-09-21-completion-audit-boundaries.zh.md)。两份记录保持有效：其权限、所有权和新鲜度决策未被取代。

## 考虑过的替代方案

**自动完成审查待办：** 宿主无法推断哪些条目仅用于记录审查，或哪些确实已经完成。自动完成会掩盖未完成的要求。

**继续展示不可用的页面工具：** 访问守卫仍会拒绝，但一致的 schema 与明确交付指引可避免引导必然失败的调用。完全移除该工具又会破坏分页审查。

**禁止每次重复完成调用：** 执行时的拒绝已经阻止状态变更，但无法阻止模型再次生成调用。反馈改善恢复，不虚构调度权限，也不改变限制。

## 影响

审查反馈增加少量固定输出成本。减少重复是模型行为目标，不是保证。不正确的完成仍被拒绝，工作或要求发生变化仍须重新审查。现有模型路由与限制不变。

## 测试

聚焦测试覆盖重复的不完整完成调用、PASS 后不变的待办状态、重新审查要求、分页读取、未完整交付和过期访问。无密钥 headless 快照启动真实 Loader、循环、文件系统、spawn 审查员及持久化：未分配的页面不在 schema 中，伪造调用被拒绝，重复完成被拒绝，明确且仅更新状态的待办记录允许一次审查后完成。脚本化适配器证明组合及记录的反馈，不证明真实模型遵从或生产启用。
