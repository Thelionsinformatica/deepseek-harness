# Agent Note: Leon 个性化设置

Status: implemented

[English](2026-08-26-leon-personalization-settings.md) | 中文

## 问题

Leon 已有固定的 preset persona，并在 Work dashboard 中提供独立记忆管理，但缺少一个统一产品界面，让用户提供持久自定义指令、选择回复语气并控制本地个人记忆行为。因此，切换模型虽然会保留 preset 与记忆记录，却没有显式、与模型无关的用户个性化层。

## 决策

`ui-settings-personalization` 功能拥有新的有序 `settings.section` 条目和 `leon-personalization` Host 设置 namespace。它持久保存自定义指令、五种稳定回复风格之一，以及工具辅助聊天中个人记忆建议的偏好。其 Host 端在核心 Leon persona 之后贡献一个 order-10 system-prompt section，因此本地与 API 模型获得相同个性化内容，同时不会替换身份、安全、工具、隐私、审批或验证策略。

自定义文本限制为 12,000 个字符，并在组装前把严格 prompt-variable 大括号转换为普通文字。回复风格选择器只改变语气。工具辅助记忆仍需要确认：启用建议不会授权自动持久写入；禁用时，除非用户明确要求，否则 agent 不得建议或创建个人记忆。

记忆控制复用现有 `personal-memory` 设置 namespace 和 runtime watcher，而不创建另一个存储。批量删除使用现有、可审计的 `memoryCandidateReview` Remote，要求当前会话和可见确认，以有界批次删除所有个人记忆状态，并且绝不删除聊天、项目记忆或项目文件。

## 验证

Host 测试证明 schema 验证、prompt 顺序、实时采用设置、文字大括号安全、确认措辞与释放。Client 测试证明指令保存、风格选择、两个记忆开关、破坏性确认边界以及无会话保护。组装后的 Web 应用通过 GUI 与 replay snapshot gate，随后在真实浏览器中检查设置页面。

## 考虑过的替代方案

- **仅在固定 Leon preset 中保留个性化**：拒绝，因为每项用户偏好都需要修改部署配置，并且可能在本地模型与 API 模型之间产生差异。
- **让每个模型分别保存指令和回复风格**：拒绝，因为切换模型会改变 Leon 的行为，而不是保留统一、与模型无关的用户偏好。
- **通过建议开关启用个人记忆自动写入**：拒绝，因为允许建议的偏好不得授予持久写入权限，也不得削弱显式审查。

## 后果

Leon 现在拥有类似 Work 体验的持久、与模型无关的个性化层。从本地模型切换到 Gemini 或 OpenAI 不再改变用户配置的指令或所选语气，但较小的本地模型可能无法同样稳定地遵循语气细节。个人记忆继续保持本地、所有者隔离、可检查且受显式控制。

本增量不会为每个模型推断不同个性，不会通过云账户同步偏好，也不会从“个性化”页面删除 workspace／项目记忆。这些边界是有意设计：个性属于用户偏好；远程同步需要独立信任模型；项目记忆管理仍限定在其项目内。
