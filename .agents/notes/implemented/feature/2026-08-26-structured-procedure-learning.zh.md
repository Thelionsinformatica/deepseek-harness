# Agent Note: 已验证过程的结构化学习

Status: implemented

[English](2026-08-26-structured-procedure-learning.md) | 中文

## 问题

标记为过程的文本记忆无法证明步骤成功、区分成功轨迹与失败尝试、表达环境前置条件、安全过期，或在复用前要求独立验证。把这类文本当作可执行指导，会让模型把自己未经验证的声明提升为持久行为。

## 决策

`ProcedureLearningService` 拥有独立的本地 `procedure_learning` 领域。工具 Consumer 从唯一且已持久化的 `tool/call` + `tool/result` 对中派生一次或多次成功观察，并采用同一会话中另一个独立且成功的验证器。调用与结果的关联必须同时匹配调用 id、轮次和步骤；重复 id 或结果会因歧义而被拒绝。服务从这些观察中派生可执行步骤，存储结果摘要而非结果内容，并在持久化之前拒绝失败轨迹、重复调用标识、混合会话证据、无效有效期窗口和类似凭据的保留字段。workspace 注册表提供作为 `cwd` 前置条件持久化的规范路径。

每个提案都以 `candidate` 开始，且无法用于复用。`procedure_inspect` 会在同一 workspace 内公开其精确步骤、验证器、前置条件、状态和有效期，使人工能够先行检查。部署拥有的审查者只有在活动根轮次中最新的直接人工消息包含独立成行的精确 `/procedure-review <id> <revision> <accept|reject>` 命令时，才能通过存储领域的原子变更接受或拒绝一个精确 revision。撤销采用等价的精确命令；普通人工文本、模型自主行为和子代理轮次都会被拒绝。只有来自精确 workspace 的 `validated` 记录可以复用，并且要求所有精确前置条件匹配、尚未到达重新验证时间且有效期窗口尚未过期。被阻止的记录会携带其验证器，以便通过普通权限检查重新验证。验证器失败会提交一个 `stale` revision；之后验证器成功时，只有提供新的有效期窗口才能重新激活。精确 revision 也会防止重新验证和撤销被并发替换。

该服务仍是选择加入的 Host 能力。当它与 workspace 和代理注册表组合启用时，根插件会注册一个稳定的策略提示词，以及用于提案、检查、审查、搜索、重新验证和撤销的六个显式模型工具。Consumer 从不可变会话日志中读取权威结果，并返回精确的已审查步骤，但不会授予已存数据指令或执行权威。它不会添加自动观察器或浏览器 Remote。

## 验证

`procedure-learning.acceptance.spec.ts` 在不创建持久记录的情况下拒绝失败和类似凭据的提案；证明候选项在审查前不可复用；按精确 revision 串行化冲突审查；在新服务实例中重新打开相同介质；只为匹配的 workspace 和前置条件检索已审查步骤；阻止到期需重新验证的过程并返回其验证器；把失败的重新验证标记为 stale；在验证器成功并提供新有效期后重新激活；并在过期时阻止复用。

`procedure-tools.acceptance.spec.ts` 驱动真实 AgentLoop 和工具注册表。其测试 `learns reviewed successful tool evidence and reuses exact steps after a model switch` 证明成功的执行与验证器调用/结果、提案、候选项检查、拒绝把普通人工轮次当作审查权限、人工通过精确命令直接接受、摘要持久化、同一 workspace 中采用另一模型的新会话、精确步骤恢复，以及使用恢复参数成功执行和验证。第二个测试证明重复调用 id 会因歧义被拒绝，而不会被学习。

## 考虑过的替代方案

- **在普通记忆中存储自然语言过程**：拒绝，因为文本没有结构化前置条件、验证器标识、证据摘要、生命周期或原子提升状态。
- **自动提升任何成功工具调用**：拒绝，因为工具成功并不证明用户目标或独立后置条件，而且模型不得批准自己的持久行为。
- **把完整工具结果或会话历史作为证据持久化**：拒绝，因为这会扩大敏感数据保留，而摘要与调用标识足以用于本地关联。
- **把任何直接人工消息视为审查权限**：拒绝，因为否则模型可以在无关人工轮次中批准自己的候选项。直接消息必须授权精确 id、revision 和动作。
- **与模型工具一起添加浏览器审查 UI**：暂缓；精确命令路径现在已经可审计，之后 UI 可以发出同一权限操作，而无需削弱状态机。

## 后果

Leon 具备了提供方和模型无关的已审查过程记忆持久基础和面向模型的 Consumer，包括确定性阻止与重新验证。它可以显式提名精确、成功的实时工具证据，并在会话和模型切换后恢复已审查步骤。它不会自动提名轨迹，也不会自动执行回忆的过程。可选服务启用时，稳定提示词和六个 schema 会产生固定模型 token 成本；各操作会追加在该可缓存前缀之后。
