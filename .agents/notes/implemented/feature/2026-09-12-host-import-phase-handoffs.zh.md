# Agent Note: 宿主导入阶段交接

Status: implemented

[English](2026-09-12-host-import-phase-handoffs.md) | 中文

## Problem

模型轮次结束不能证明同伴工作已完成。重复相同的宿主请求可能耗尽任务预算而不产生新证据，仅修复产物也不能证明协作或有效审核。

## Decision

隔离的宿主变体通过原生 TeamService 创建调查者和 checker，然后才请求 Lead 工作。[实验室](../../../../examples/headless-agent/README.zh.md) 保持 48 次调用、15 分钟截止时间及最后八次 checker 专用调用。宿主交接检查产物摘要、原生任务修订和验证证据；进程内记录对每个参与者/签名组合仅放行一次。仅 token 计数或时间变化不能重发请求。只有模型调用的原生工具才能提交任务或创建证据。现有的当前摘要验证器决定是否完成。

## Alternatives considered

**重复固定反馈。** 拒绝，因为未变化的拒绝结果不授权消耗更多轮次。新的证据状态允许另一次有界请求。

**宿主完成任务。** 拒绝，因为这会使比较奖励编排捷径，而不是经过验证的 agent 工作。

## Consequences

变体可能在产物有效但任务未关闭时以受阻状态结束。它恰有两名队友，而不是两名调查者再加额外审核者。交接记录仅在当前进程内生效；持久化的 STOP、截止时间、预算和身份在重启后保留，但这不是突然崩溃恢复或通用任务引擎。原生 Loader 测试使用确定性适配器验证会话、工具执行、同伴证据和最终批准；本地模型性能需要独立保留的尝试。
