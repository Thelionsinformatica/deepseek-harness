# Agent Note: Host 管理的模型分配

Status: implemented

[English](2026-09-13-host-model-assignments.md) | 中文

## Problem

选择对话模型并不会配置独立调用的标题、摘要、委派工作代理或完成审查员。没有消费方的纯设置展示会误导用户对功能的理解。

## Decision

[agent-default-model](../../../../packages/core/agent-default-model/README.zh.md) 中的可选策略拥有五种 Host 指定功能的单一设置分节。现有消费方在正常日志记录或子代理创建前解析选择。未配置的组合保持其行为，包括冻结实验。只有部署明确列出的提供商被视为本地，外部路由需要功能级授权。UI 使用带乐观并发控制的现有设置 API，刷新目录不执行推理。

## Alternatives considered

**另一个多代理框架：** 现有委派和审查已经负责会话及完成证据，因此拒绝。

**按显示名称或 localhost URL 路由：** 名称不能确立权限，网关可能转发至收费外部提供商，因此拒绝。

**为参考图片中的每项功能提供可编辑占位项：** 不受支持的 MCP、审批和技能消费方会错误暗示独立派发，因此拒绝。

## Consequences

UI 分离主模型、辅助和协作分配，不更改权限策略、不创建额外代理、不削弱审查。已有子代理保留捕获的模型；清除功能恢复消费方继承配置。功能级 API 授权不是费用上限。无密钥 Loader 测试记录真实标题路由；UI 和服务测试覆盖写入、冲突及外部授权拒绝。收费推理与实验混合预设不属于此次交付。
