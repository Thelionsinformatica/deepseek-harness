# Agent Note: 会话作用域内的记忆与能力总览

Status: implemented

[English](2026-09-21-memory-capabilities-overview.md) | 中文

## Problem

已安装的 skill（技能）可能对当前 preset 不可见。单独的记忆编辑器无法解释这一差别，而记录某项能力存在的记忆会在会话组合变化后陈旧。

## Decision

现有记忆控件提供只读总览标签页。打开标签页或用户刷新时，从各自服务读取项目记忆、个人记忆和会话 skill。资料卡显示有效 preset 和有界的各来源记录数。可选择节点、缩放和列表视图支持检查；连线仅表示已计算的相似边，且端点修订号必须与显示的记忆一致。分组位置不暗示事实关系，视图不维护第二个记忆数据库。个人记忆的写入、确认、脱敏和禁用仍由现有管理控件负责。

`skill.inspect` 报告实际持久化 preset、作用域内的提供方快照以及已注册 skill 加载工具的可见性，不启动 agent（智能体）或推理。执行授权明确为 `not-evaluated`：检查不运行防护规则或请求审批，目录可见性不保证调用获准。会话变化使视图失效。提供方缺失会显示对应来源的错误，部分快照保持不完整状态，安装或工具注册均不代表功能测试通过。

总览显示已返回记忆的最新存储版本和更新时间，而非完整审计历史或历史差异。日历标记这些时间戳对应的日期，并非每次过去的编辑。页面明确说明有界分页，并单独限制图中的节点数量，不限制可访问的条目列表。各来源错误仍显示为错误，而非零条记录。skill 描述是非可信展示数据，检查不会执行它。

## Alternatives considered

**导入另一个 agent 的记忆或扫描所有 preset。** 拒绝此方案，因为它绕过所有权，将已安装材料与会话可见的能力混合。

**使用模型构建图。** 拒绝此方案，因为现有记录的分组是确定性的，不需要 API 消费或事实推断。

**将所有已安装 skill 声称为已测试。** 拒绝此方案，因为发现和加载成功不代表外部依赖或工作流正常。

**在检查目录时运行执行防护规则。** 拒绝此方案，因为防护规则依赖调用参数，并可能请求审批或消耗执行状态。授权属于实际调用，而非只读目录检查。

## Consequences

用户无需改变模型、权限、个人记录或当前 preset，即可检查记忆及能力可用性。更新按需进行，而非持续后台 agent。历史记忆差异和自动经验晋升不在此次实现范围内。

## Verification

组件测试覆盖独立来源失败、部分目录、禁用的个人记忆、刷新及陈旧响应。宿主测试覆盖实际 preset 解析、作用域隔离和只读检查，包括加载工具可见但执行防护规则拒绝实际调用的情况。协议拒绝缺失或虚构的授权状态。浏览器场景使用发布的 Web 组合及隔离的合成数据，对比可见输出并检查没有额外模型响应或记忆修改。这些检查不能证明模型会在不受限制的真实任务中选择某项 skill。
