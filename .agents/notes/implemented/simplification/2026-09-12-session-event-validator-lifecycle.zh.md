# Agent Note: 共享会话事件验证器生命周期

Status: implemented

[English](2026-09-12-session-event-validator-lifecycle.md) | 中文

## Problem

Plan-mode 与 web-access 配套检查重复实现已有历史回放、会话创建处理和分发前拦截。独立副本可能在时序或释放行为上发生偏差，使无效事件进入已提交日志。

## Decision

Session 不变量入口导出一个小型无状态生命周期辅助函数。消费方保留事件选择、负载验证、包注册及其绑定的失败报告函数。辅助函数负责遍历已有会话、验证创建时的 seed，并在注册子上下文中观察分发前事件。释放会移除监听器。它不保存投影状态，也不修改准入规则。

## Alternatives considered

**提取到不变量注册表** 需要对 Session 的反向产品依赖，或引入没有其他消费方的通用回调 API。Session 已拥有两个配套检查所观察的生命周期。

**抑制克隆检测器** 会保留重复所有权并允许未来行为偏差。格式修改不能建立共享生命周期。

## Consequences

包依赖、持久化格式、事件语义、验证阈值和运行时设置均不改变。无状态验证器必须同步且无副作用；有状态不变量仍负责已提交事件的状态转换。针对性测试覆盖旧历史、新建带 seed 的会话、追加及下游观察前拒绝、安装失败清理、释放和重新加载。现有 plan 与 web 行为测试仍为必需。没有模型可见变化，因此已有 transcript 快照仍适用，无需重新记录。
