# Agent Note: Web 预设测试拥有独立的会话存储

Status: implemented

[English](2026-09-21-web-preset-session-isolation.md) | 中文

## 问题

随附的 Web 组合从 `DSH_HOME` 解析 JSONL 会话根目录。仅隔离设置和通用存储，仍会让会话追加操作写入操作者的真实会话历史。随机会话标识符能避免冲突，却不能隔离这些写入。

## 决策

[`bootWeb`](../../../../apps/cli/tests/web-agent-presets.e2e.ts) 在 Loader 挂载组合之前，将 `session-persistence-jsonl.root` 覆盖为临时设置文件旁的 `sessions` 目录。每次调用辅助函数时，真实的持久化后端及其持久性监听器都保持启用。

共享 fixture（测试前置数据）使用另一个包含哨兵文件的临时 `DSH_HOME` 启动，然后恢复进程环境。无需密钥的回归测试追加一个预设选择事件，等待会话刷新，读取预期的临时日志文件，并通过后端的原始产物读取器验证持久化内容。外部主目录仅保留内容未变的哨兵文件。移除根目录覆盖项后，预期文件的读取就会失败。

## 考虑过的替代方案

**禁用会话持久化。** 这能避免磁盘写入，但会从组装后的组合中移除真实的持久性行为。

**让辅助函数将 `DSH_HOME` 替换为设置目录。** 这会掩盖存储根目录彼此独立的事实，也会干扰有意从另一个 harness 主目录解析用户预设的测试。

## 影响

Web 预设测试保留真实的会话持久化，同时不继承操作者的会话目录。回归测试使用合成数据，不调用模型。本决策不会改变生产路径，也不会移除早先测试运行留下的产物。
