# Agent Note: 提供方无关的受控 Memory V2

Status: proposed

[English](2026-08-22-provider-neutral-controlled-memory-v2.md) | 中文

## 问题

Leon 已具有持久本地记忆与只读自动回忆，但在扩展到外部提供方之前，仍缺少一条用于自动提取、确定性写入决策、决策历史和收益评估的结构化可审计路径。

## 提案

分阶段交付 Memory V2：先实现可观察性与影子模式，再实现确定性写入策略，最后在本地证据支持后加入可选语义检索。

## 决策架构

- 保持 `ctx.memory` 为提供方无关的 seam。
- 添加 `MemoryPolicyService`、`MemoryCandidateExtractor` 与 `MemoryCandidateJournal` 角色。
- 为影子、拒绝、确认和存储结果引入带版本的 `MemoryDecisionEvent`。
- 将检索扩展为具有 token 限制与有效性过滤器的混合流水线。
- 没有显式功能开关与策略验证时，保持自动写入禁用。

## 后果

- 记忆模块保持独立于所选模型与提供方。
- 检索可以改善连续性，而不会向已存内容授予系统权威。
- 持久决策轨迹使审查与回滚可以实际执行。
- Letta 的采用保留为后续实验步骤。
- 首次[直接 provider 实验](../../rejected/architecture/2026-08-25-direct-letta-memory-provider.zh.md)未通过兼容性门禁；重新评估现在具有明确的安全、recall、延迟和成本门槛。

## 考虑过的替代方案

**在取得影子证据前启用自动写入。** 已否决，因为误报保留会早于安全运行所需的审查、回滚和策略信号。

**将 Letta 作为核心记忆实现。** 已暂缓，因为本地的提供方无关 seam 必须保持为稳定所有者；在本地决策路径可度量后，Letta 可以作为实验提供方加入。

## 验收标准

- 任何操作都不得跨 workspace 所有权读取或写入。
- 未经已配置的授权与策略决策，不得执行语义记忆写入。
- 回忆出的敏感数据绝不能获得指令权威。
- 升级到非本地服务需要显式同意。

## 风险

- 提取与检索策略可能保留无关事实或漏掉有用事实。
- 如果事件不保留策略版本，策略版本变更会使历史决策无法比较。
- 混合检索可能增加超过其可测收益的 token 与延迟成本。
- 影子候选项的累积速度可能快于操作者审查速度，因此仍需保留与审查限制。
