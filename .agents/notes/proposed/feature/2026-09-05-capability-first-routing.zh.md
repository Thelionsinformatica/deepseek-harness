# Agent Note: 能力优先的本地路由

Status: proposed

[English](2026-09-05-capability-first-routing.md) | 中文

## 问题

面向文本的专长路由和编号 Goal Round 可能选中不支持图像的模型。提示词长度也不能证明专家模型会改善答案。

## 提案

部分实现把显式视觉路由置于准入规则之前，并提供可配置的仅按长度提升专家层级的开关。两者均由部署显式启用。宿主根据持久化的用户消息和工具结果传入保守的图像历史标记；即使经过压缩（compaction），图像仍可使视觉路由保持选中。现有可用性和授权检查继续生效。启用前仍需完成组装应用测试，并独立验证任务失败处理。

## 考虑过的替代方案

**只替换专家模型：**专长和 Goal Round 仍可能覆盖它，因此无法解决优先顺序问题。

**总是选择最大模型：**参数量本身不是任务能力的证据，还会不必要地增加本地资源消耗。

## 验收标准

验证视觉准入在专长、恢复和 Goal Round 中的行为；验证保留历史中的图像；在真实组合中证明任务检查失败后的有界升级；保留外部授权并报告所选路由。仅通过分类器测试不足以启用。

## 风险

声明的视觉路由仍可能不可用或配置错误。分类器不检查模型权重、不验证任务正确性，也不实现完整能力注册表。兼容默认值保留现有行为，直到部署显式启用。
