# 创造模式预设

[English](README.md) | 中文

`cordis` preset 提供编程工具和运行中组装的创作工具。其执行权限仍相当于 shell 访问；完成审核不会使任意创作的插件变得安全。

## 完成与进程保护

目标完成要求当前目标具有非空且全部完成的任务列表，并通过宿主现有 `spawn` provider 执行的独立审核。宿主的辅助审核模型选择优先于继承的路由。审核采用 Leon 的限制：4096 个输出 token、每个父轮次两次尝试、返回的反馈最多 6000 个字符。缺少任务证据、拒绝、无效的结构化输出或审核不可用都会让目标保持活动状态。[目标工具](../../../../../packages/goal/tool-goal/README.zh.md)负责这些检查和私有的证据读取工具。

在 Windows 上，`pwsh` 与 Leon 一样拒绝终止宿主进程，并要求使用受管理的后台服务启动及单独的前台健康检查。普通编程和组装工具仍可使用。preset 不会改写会话已保存的 sandbox 模式，包括 `danger-full-access`；这些工具级保护不能替代 sandbox 或审批策略。

## 模型体验与限制

组装后的目标工具说明任务和审核要求，完成被拒绝时会向协调者返回反馈。独立审核者获得宿主提供的证据读取和结构化结论工具，不获得协调者的 shell、写入或组装工具。preset 不选择 provider 凭据或新的默认模型。这些策略在挂载 preset 时生效；编辑文件不会热重载已经挂载的 agent。
