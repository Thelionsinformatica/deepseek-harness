# Leon Memory V2 路线图

[English](leon-memory-v2-roadmap.md) | 中文

## 阶段

### 阶段 M2-00 — 基线审计

- 验证基线提交或标签。
- 汇总现有测试清单。
- 验证隔离、重启与 workspace 流程。

### 阶段 M2-01/02 — 可观察性

- 添加记忆事件。
- 添加用于决策与阻止操作的指标和仪表板。

### 阶段 M2-03 — 影子模式与提取

- 使用 `category`、`confidence` 与 `importance` 提取候选项。
- 将其存储在 journal 或待处理队列中，不执行持久记忆写入。

### 阶段 M2-04/05 — 确定性策略与版本控制

- 定义决策引擎。
- 记录 `policyVersion`、原因与轨迹。

### 阶段 M2-06 — 自动写入控制

- 添加按用户与按 workspace 的功能开关。
- 添加按类别逐步启用的规则。

### 阶段 M2-07 — 混合检索与安全上下文

- 保留当前词法回忆。
- 添加可选本地语义检索。
- 添加具有 token 限制和优先级意识的 `MemoryContextComposer`。

### 阶段 M2-08 — 冲突与时间有效性

- 添加显式取代与过期支持。
- 查询默认忽略陈旧版本。
- 添加限定于 workspace 的已保存记忆管理，并提供明确确认、不含内容的审计和只读回滚。

### 阶段 M2-09 — LEON-EVAL 与稳定性

- 运行初始测试套件。
- 修复严重回归。

### 阶段 M2-10 — 可选 Letta 实验

- 比较 `LocalMemoryProvider` 与 `LettaMemoryProvider`。
- 仅在取得客观改善后迁移。

## 阶段推进规则

- 满足以下条件前不得推进阶段：
  - 必需的阶段测试通过；
  - 回滚已有文档记录；
  - 涉及风险的差异已经审查。

## 建议时间范围

阶段 0 与 1 预留 1–2 周，阶段 2–5 预留 2–3 周，初始评估与稳定预留 1–2 周。

## 优先级规则

- 第一：安全与隔离。
- 第二：一致性与可逆性。
- 第三：性能。
