# @deepseek-ai/dsh-client-ui-voice

[English](README.md) | 中文

本包为 Leon 提供一个本地优先语音循环和一个如实呈现的环境活动读数。会话级 `conversation.input.right` slot 负责开始麦克风、停止麦克风和打断语音。`conversation.composer.dock` slot 展示就绪、聆听、本地转写、思考、活动工具、待处理交互、说话、打断和错误状态；这些状态均来自普通 Conversation 快照，而不是平行的进度通道。

`BrowserVoiceCaptureDriver` 将 `getUserMedia`、`MediaRecorder`、Web Audio 测量和资源释放封装在狭窄的 `VoiceCaptureDriver` 接口之后。`VoiceCaptureController` 只发布可 JSON 化的视图；录制的 `Blob` 保持私有。已配置的转写器会为当前处理操作接收一个 `AbortSignal`，并且必须在捕获被取消、Session 切换或插件被 dispose 时及时结束。内置适配器在把临时音频片段发送给 Leon 的同源回环宿主时会转发该信号。宿主会保持一个惰性启动的本地 Vosk worker，模型只加载一次，音频片段串行通过该 worker；取消、超时或协议故障会销毁它。组件通过 Conversation 包的普通 `InputActions.setDraft` 和 `submitTracked` 路径写入识别文本，而不会发明第二条消息通道。

`BrowserVoicePlaybackDriver` 使用浏览器的操作系统语音目录，并且只接受标记为 `localService` 的语音。它优先选择巴西葡萄牙语以及已安装的 Microsoft Daniel，其次选择其他本地葡萄牙语语音；当只有远程语音时快速失败。播放可在 `VoicePlaybackDriver` 后替换；本包不捆绑语音模型、音频录音或云端 TTS 依赖。

语音提交的提示词会排入且仅排入一条因果语音回复，并在对应轮次结束后播放。宿主接纳时会返回精确的持久 Chat 用户消息 id；只有该消息解析出的轮次可以发声。即使宿主回执乱序到达，并发的后续消息仍按提交顺序朗读。恢复的历史记录、之后键入的轮次、被打断的 assistant 输出、推理和工具块绝不会进入语音；围栏代码会被移除，长文本会被限制长度。

在 Leon 说话时选择麦克风只会取消音频并开始新的捕获，不会取消 agent 或其工具。实时语音会话会在语音回答完成（包括刻意保持静音的回答）后重新打开麦克风，并提供独立的结束按钮；该按钮停止捕获和播放，但不停止任务。当 agent 正在工作时捕获的语音会进入普通队列。只有在捕获开始时输入框为空且之后未被修改，系统才会自动发送；键入文本、附件、引用和斜杠命令会让转写保留在草稿中等待审核。待处理的审批/问题以及非普通输入事务仍是阻塞边界，因此语音不能绕过明确的人机交互。结束实时模式或切换 Session 会使延迟的宿主回执失效；已接纳消息若在 30 秒内未进入 Chat 投影，语音模式会结束，但任务不会被取消。

## 模型体验

无。语音捕获、播放和活动 HUD 不注册任何面向模型的工具或提示词。识别文本进入既有用户消息流水线，因此已配置的模型路由器继续完全负责本地模型与 API 的选择。

#### KV Cache 影响

除普通的已识别用户文本外没有影响。麦克风音量、录音字节、播放状态和 HUD 状态绝不会进入提供方上下文。

## 已知限制与后续工作

- **转写以音频片段为单位** —— 语音先在本地录制，捕获结束后才进行转写。实时模式按已完成轮次连续运行；尚未实现局部转写和同时进行的全双工流。
- **首个播放提供方位于浏览器本地** —— 可用语音会随 Windows 和浏览器变化。未来的宿主提供方可以在不修改控制器的情况下加入产品可控语音。
- **语音刻意保持选择性** —— 只有语音提交后新产生的已完成回答会被朗读。键入的提示词、恢复的历史记录、推理、工具参数、围栏代码和空回答均保持静音。
- **插话保证任务安全，而不是取消任务** —— Leon 工作时可以捕获后续语音，但打断语音只会停止音频。识别出的消息遵循普通队列策略，不会暗中取消工具或当前轮次。
- **回复关联具有因果性** —— `InputActions.submitTracked` 携带宿主实际接纳的精确消息 id，因此完全相同的并发文本不会让 Leon 朗读错误轮次。
- **草稿审核默认关闭自动发送** —— 只有空白且未变化的输入框才允许捕获后自动发送。已有或并发键入的文本、图片、引用和斜杠命令都保留在草稿中等待人工审核。
- **投影超时只停止语音，不停止工作** —— 若已接纳的用户消息在 30 秒内仍不可观察，实时语音循环会以可见状态结束，而普通 Conversation 和任务继续作为权威来源。
- **不捆绑自定义或克隆语音** —— 未来的安装程序必须分别验证引擎、模型、再分发条款以及任何参考语音的授权。
- **资源遵循客户端插件生命周期** —— dispose 会中止捕获、进行中的转写和播放，然后忽略延迟到达的浏览器回调。切换 Session 会中止捕获和转写，并静默停止语音，确保一个会话的内容绝不会覆盖另一个会话朗读。
