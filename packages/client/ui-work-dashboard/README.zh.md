# @deepseek-ai/dsh-client-ui-work-dashboard

[English](README.md) | 中文

本包在空会话中使用 Leon Work 概览填充可选的根作用域 `conversation.hero.dashboard` 座位。项目数、运行中的工作、待交互项、已完成工作以及最近三条会话，全部来自现有 Workspace 与 Session 投影。对于浏览器无法权威观测的提供方、GPU 或 API 健康状态，仪表板不会合成虚假信息。

本包只拥有产品呈现与导航。`新建任务` 委托给 Workspace runtime，最近工作行委托给 Session runtime，而 conversation 包继续拥有常驻 composer 与活动任务表层。会话头部的 `审查记忆` 操作会打开四个视图：只读的记忆与技能概览、按 workspace 隔离的影子建议、workspace 已保存记忆管理，以及单独按所有者隔离的个人记忆面板。每次添加、纠正、删除或启用状态变更都需要可见确认；禁用个人记忆后仍可检查和删除。授权、功能开关、settings 持久化、存储、遮蔽、审计与只读回滚仍只归 Host 所有。巴西葡萄牙语是产品原生文案，并与完整的英文和简体中文词典并列。将本包从 Web 组合中移除后，会恢复普通的无仪表板 Hero 并移除审查控件，同时不改变任何记忆域。

API 费用是估算值，并非账单。未定价调用会显示部分估算警告；如果所有调用都未定价，卡片显示费用未知，而不是零美元总额。指标卡片的标签和详情换行显示，不会截断计费说明。

个人面板区分待确认与已确认的事实，并标识已确认的画像选择。人工可以重新确认未修改的文本，也可以明确把事实加入或移出有界、独立于查询的画像。每项操作都会展示精确文本、要求确认，并通过 Host 提交当前 revision；打开或检查面板时绝不会静默修改记录。被遮蔽、禁用或只读的记录不能被确认或选入画像。模型提出的事实在确认前不会进入自动回忆；已有的确认元数据不会被迁移。

个人面板包含可选的“了解你”访谈。姓名、工作、沟通方式、目标和确认偏好在逐项审查并通过现有已确认个人记忆操作保存之前，仅作为浏览器组件中的草稿。用户可以跳过问题；关闭访谈会丢弃未保存的草稿。记忆被禁用或处于只读状态时不能保存。偏好绝不会授予权限。访谈不调用模型；获准保存的记忆之后可能按照现有召回与提供方配置进入模型上下文。此处未实现聊天中的主动访谈。

只读的概览标签页仅在打开或手动刷新时加载项目记忆、个人记忆与会话作用域的技能检查。智能体资料显示有效预设与各来源记录数，包括部分结果和不可用状态。可缩放的关系图每组最多显示十二条可选择记录，并提供缩放控件；列表视图与选中记录详情展示返回的数据，不推测语义关联。个人记忆启用状态、目录完整性、模型可见性与检查时间各自独立显示。执行授权明确标记为未评估：打开目录不会运行防护规则或发起审批请求，可见的技能在调用时仍可能被拒绝。技能注册不代表运行测试通过。预设或会话改变时丢弃旧检查结果；来源失败时显示错误，同时保留成功来源的结果。打开此视图不会启用记忆，也不会将数据发送给模型。

最近记录变更列出每条返回记忆修订的当前更新时间。日历在这些时间戳的最新月份中标记对应日期；它不是审计轨迹、历史差异、每次编辑的计数或后台构图活动。视图最多读取一百条包含所有状态的项目记录与一百条有效个人记录；分页和不完整目录会标记为部分视图。它不会合并工作区、从记忆内容推断关联或持久化另一个图数据库。

概览分别标记 workspace 与个人图健康状态：pending、computed、empty、stale、failed 或 unavailable。只有 computed 快照绘制相似边，并同时匹配记忆 id 与修订号。故障详情来自脱敏代码白名单；绝不渲染后端消息。位置只用于分组，不暗示关联；图不可用时不显示装饰性连线。

## 模型体验

无，因为仪表板只读取浏览器投影并调用导航或本地审查操作，不会把其文案、候选项或状态加入模型请求。

#### KV Cache 影响

无；该包既不组装也不发送提供方请求。

## 已知限制与暂缓事项

- **运行时健康状态目前只是说明，不是实时数据** — 模型、GPU、Ollama 和云提供方健康状态需要先有权威的客户端投影，仪表板才能在不猜测的情况下呈现。活动模型仍由现有 composer 芯片披露。
- **最近工作刻意保持紧凑** — 首版最多显示三条非空、未归档的普通会话。产物、计划任务、全局记忆范围与权限审计卡片属于后续独立里程碑。
